# Project notes

- Static site (GitHub Pages, `CNAME` = josephsalazar.com). No build step.
- Previewing: the user uses VS Code "Open with Live Server". Do NOT start local servers (e.g. `python3 -m http.server`).
- Release landing pages live at `/<slug>/index.html` and share `assets/css/release.css`.
- Link order for releases: Website, YouTube, Spotify, Bandcamp, Apple Music, Amazon Music, Steam, itch.io (omit any that don't exist).
- Host images locally in `assets/images/`; old `josephsalazar.com/wp-content/...` URLs are dead.
